## 📖 About

Markdown is a lightweight plain-text formatting syntax designed to be readable as-is while rendering beautifully on the web. It powers documentation on GitHub, comments on Reddit, messages on Discord, and much more.

This repository is a hands-on reference collection — every feature has a dedicated `.md` example file you can open, copy from, and learn by doing.

> **External cheatsheet:** A great companion resource is [Adam Pritchard's Markdown Cheatsheet](https://github.com/adam-p/markdown-here/wiki/Markdown-Cheatsheet).

## ✨ Features Covered

- **Text Formatting** — bold, italic, strikethrough, inline code
- **Headings** — all six levels (H1–H6)
- **Lists** — ordered, unordered, nested, and task lists
- **Blockquotes** — standard and GitHub-flavored callout alerts
- **Footnotes** — inline reference annotations
- **Tables** — basic and column-aligned
- **Links & Images** — hyperlinks, embedded images, clickable icon badges
- **Code Blocks** — inline, fenced, with syntax highlighting for 15+ languages
- **Keyboard Keys** — `<kbd>` styled shortcut keys
- **Collapsible Sections** — `<details>` expand/collapse blocks
- **HTML in Markdown** — inline HTML elements, line breaks, alignment
- **Comments** — invisible annotations in Markdown source
- **Diagrams** — Mermaid flowcharts, sequence diagrams, Gantt charts
- **Math** — LaTeX/KaTeX inline and block equations
- **GitHub Features** — stats cards, streak badges, trophies, skill badges, repo cards, contribution snake
