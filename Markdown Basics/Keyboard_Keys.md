# Keyboard Keys

Use the HTML `<kbd>` tag to render keyboard shortcuts with a key-cap appearance.

**Syntax:**

```html
<kbd>Ctrl</kbd> + <kbd>C</kbd>
```

**Rendered:**

<kbd>Ctrl</kbd> + <kbd>C</kbd>

---

## Common Shortcuts

| Action | Shortcut |
| :----- | :------- |
| Copy | <kbd>Ctrl</kbd> + <kbd>C</kbd> |
| Paste | <kbd>Ctrl</kbd> + <kbd>V</kbd> |
| Undo | <kbd>Ctrl</kbd> + <kbd>Z</kbd> |
| Save | <kbd>Ctrl</kbd> + <kbd>S</kbd> |
| Find | <kbd>Ctrl</kbd> + <kbd>F</kbd> |
| Select All | <kbd>Ctrl</kbd> + <kbd>A</kbd> |

---

## Mac Keys

| Action | Shortcut |
| :----- | :------- |
| Copy | <kbd>⌘</kbd> + <kbd>C</kbd> |
| Spotlight | <kbd>⌘</kbd> + <kbd>Space</kbd> |
| Screenshot | <kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>4</kbd> |
