# Icons in Markdown

Use [Simple Icons](https://simpleicons.org) for brand logos via CDN.

> ⚠️ Always use the latest version tag. The example below uses `@v11`.

**Syntax:**

```html
<img align="left" alt="Python" width="30px" src="https://cdn.jsdelivr.net/npm/simple-icons@v11/icons/python.svg" />
```

**Rendered:**

<img align="left" alt="Python" width="30px" src="https://cdn.jsdelivr.net/npm/simple-icons@v11/icons/python.svg" />

<br><br>

Find all available icons at: [simpleicons.org](https://simpleicons.org)
